# RecipeApp

Simple web app for managing and searching cooking recipes.

## Features
* Add, edit, view, and delete recipes.
* Filter recipes by ingredients and categories.
* SQLite / SQL database storage using Entity Framework Core.

## Tech Stack
* C# / .NET 8
* ASP.NET Core
* Entity Framework Core
